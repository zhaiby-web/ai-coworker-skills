# 小白指挥AI干活之我是产品AI是开发

> Routing Decisions to Humans — technical calls execute; product calls escalate with a recommendation.

治"AI 啥都来问我"：技术事实和机械合规它**自主执行、做完告知**（附证据和回退路径），不再问你"这样改行吗"；只有三类事来找你——影响**产品体验**、**上线范围**、**产品目标**的，而且必带推荐方案。顺带发现的体验问题（比如满是术语的报错文案）也必须上报，不许以"不在任务范围"放行。

## 何时用
- 你不懂技术，但 AI 老让你"确认"技术选择
- 你希望 AI 把技术问题自己消化掉，只拿该你拍板的事来烦你
- AI 转来别人的"二选一"，你怀疑这事早就定过了

**触发例句**：「我不懂技术，你来处理」「有问题就处理掉，别啥都问我」「这个是不是该我定？」

## 何时不用
- 你本身是工程师且想参与技术决策（直接告诉它你要参与哪类）
- 不可逆动作、花钱、权限、需正式签核的事（这些永远上报，本技能不改变）
