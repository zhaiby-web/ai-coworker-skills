# 小白指挥AI干活之验收神器

> Auditing Completion Claims — "it says done" never silently becomes "it is done."

任何"完成了/做好了/通过了/环境好了/已发布"，先别信：能查机器事实的先查，查不到的追问四件事——**完成了什么？怎么证明？还缺什么？谁接下一步？**证据分五级（E1文件写明→E5你可拍板），推断永远不许冒充已验证。

## 何时用
- AI 汇报"做完了/测试通过了/环境好了"，你想知道到底完成到哪一层
- 你转述别人的结论（"研发说改完了"），需要帮你核实再接受
- 自己要宣布完成前的自检

**触发例句**：「它说部署好了，你帮我确认下」「这个'通过了'可信吗」「验收一下这份回执」

## 何时不用
- 你以自己的直接权限拍板的事（产品决策，凭你一句话即成立，不用审）
- 纯观点讨论，没有完成声明
- 你明确说"先记下、别验证"

## 安装
SkillHub 页面直接安装，或拷贝本目录到 `~/.claude/skills/` 或 `~/.codex/skills/`。零依赖、纯提示词。
建议在全局指令（`~/.claude/CLAUDE.md` / `~/.codex/AGENTS.md`）钉一条常驻规则让它每次必查——见技能包主页说明。
