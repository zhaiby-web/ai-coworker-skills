# 小白指挥AI开发之怎么派活

> Packaging Low-Context Work — judgment stays, execution ships.

把活交给"不了解全局的执行者"（便宜的 AI、子会话、新同事）而不翻车的方法：**语义、边界、决策、验收留在懂的一侧**；执行拆成五要素任务卡——负责范围 / 不负责范围 / 输入契约 / 输出物 / 验收标准。试金石一句话：**一个称职的陌生人只凭这张卡，能不能把活干对？**回执必验收，没验收的"完成"只是穿着完成外衣的未完成。

## 何时用
- 要把开发任务派给 AI 会话或新来的同事，对方不了解你的业务
- 纠结"让他先读完所有文档再开工"（答案：不要，把上下文装进卡里）
- 派出去的活收回来了，不知道怎么验收

**触发例句**：「帮我安排新人第一周的活」「这个任务怎么拆给 AI 做」「帮我写个派工任务卡」

## 何时不用
- 活本身就是判断题（起名、取舍、语义边界）——判断永不外包
- 两分钟能自己做完的一次性小事（写卡的成本高于活本身）
